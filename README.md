# FAQ-бот репетиции

Простой консольный бот отвечает на пять известных вопросов о репетиции: время, состав команды, треки, сдача результата и призы. Вопрос пользователя приводится к набору ключевых слов и сравнивается с вопросами из `faq.txt`. Бот выводит ответ от наиболее похожего вопроса; если общих ключевых слов нет — печатает `не знаю`.

## Запуск

Нужен Python 3.10 или новее. Внешних библиотек нет.

```powershell
python bot.py
```

Задайте вопрос в терминале, например `Во сколько начало?`, `Какие есть треки?` или `Куда отправлять работу?`. Чтобы завершить программу, напишите `выход`.

## Содержимое

- `faq.txt` — пять пар вопрос–ответ, которые легко изменить без правки кода.
- `bot.py` — интерактивный терминальный бот и поиск по совпадающим ключевым словам.

Пример:

```text
> Во сколько начало?
Репетиция проходит с 18:30 до 19:30.
> Где парковка?
не знаю
```
